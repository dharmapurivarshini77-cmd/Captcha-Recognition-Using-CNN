🔐 Captcha Recognition Using CNN is a deep learning project that uses a Convolutional Neural Network (CNN) to automatically recognize characters from CAPTCHA images. 🧠 The project preprocesses CAPTCHA images by converting them into grayscale and normalizing pixel values before training the CNN model. The trained model learns character patterns and features from the dataset and can predict CAPTCHA text from new test images. 📊 The project also provides training performance visualization using accuracy and loss graphs, helping evaluate how effectively the model learns over multiple epochs. 📈 This project demonstrates the practical application of Deep Learning, Computer Vision, Image Processing, and CNN-based image recognition for automated CAPTCHA character recognition. 🤖🔤
